# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:
**Security → Report a vulnerability** on this repository
(<https://github.com/Arjuunb/nexus-trading-bot/security/advisories/new>).

Do not open a public issue, pull request or discussion for a vulnerability
while it is unpatched. A trading system can hold exchange credentials, so an
open report is an invitation.

Include what you found, how to reproduce it, and what an attacker could do with
it. Leave real API keys, exchange credentials and account identifiers out of
the report.

## What happens next

The report is visible only to the maintainer and to you. You will get an
acknowledgement, then a fix or a reasoned answer, in the advisory thread. Once
a fix is released the advisory is published with credit, unless you ask
otherwise.

## Scope

Everything in this repository: the platform (`automation-hub/`), the dashboard,
the public site, the SDKs and the deployment files.
