# Code of conduct

Four rules for issues, pull requests and reviews in this repository.

1. No signal-selling, no referral links, and no performance claims without the
   record attached. A screenshot of a P&L is not evidence of anything.
2. Disagree with the argument, not the person. Reviews and threads are public
   and permanent.
3. No financial advice, given or requested. Discuss method and mechanism.
4. Assume the person asking a basic question has been trading for a week.
   Everyone here was.

Breaches are raised privately first. Repeated ones lead to comments being
removed and, if needed, the account being blocked from the repository.
